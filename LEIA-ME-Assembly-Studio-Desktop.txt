ESCOLHA O ARQUIVO PARA O SEU COMPUTADOR

Windows x64: Assembly-Studio-Desktop-1.14.0-win-x64.exe
Execute o instalador e escolha a pasta. Depois, abra Assembly Studio Desktop
pelo menu Iniciar ou pelo atalho criado.

Linux Debian/Ubuntu x64: Assembly-Studio-Desktop-1.14.0-linux-amd64.deb
Abra o arquivo no instalador de pacotes do sistema. Alternativamente, na pasta
do download, execute:
sudo apt install ./Assembly-Studio-Desktop-1.14.0-linux-amd64.deb

Outras distribuições Linux x64: Assembly-Studio-Desktop-1.14.0-linux-x64.tar.gz
Extraia o pacote e execute assembly-studio-desktop dentro da pasta extraída.
Mantenha os arquivos juntos. Bibliotecas gráficas do sistema são necessárias.
Não execute como root nem desative o sandbox para contornar incompatibilidades.

Mac com Apple Silicon (incluindo MacBook Air M1):
Assembly-Studio-Desktop-1.14.1-mac-arm64.dmg

Mac com processador Intel:
Assembly-Studio-Desktop-1.14.1-mac-x64.dmg

PROJETOS E ARQUIVOS

Use Open project para abrir projetos JSON do Assembly Studio ou dos módulos.
Use Save project para salvar o projeto integrado em um arquivo .assembly.json.
Atalhos: Ctrl+O/Ctrl+S; no Mac, Cmd+O/Cmd+S.
O mesmo projeto pode ser aberto na versão web e na versão desktop.

Para importar FASTA, GenBank, SnapGene ou leituras de sequenciamento, use os
controles de importação do módulo correspondente.
As exportações FASTA, TAB, GenBank, SnapGene e ZIP permanecem disponíveis.

Salve antes de fechar: esta versão NÃO salva projetos automaticamente.
Atualizações são manuais: instale a versão mais recente e reabra o JSON salvo.

USO LOCAL E INTERNET

Os motores de cálculo, incluindo os componentes Python, já estão no pacote.
O usuário não precisa instalar Python ou Node.js.
Montagem, análise local dos oligos, verificação e exportações funcionam no
computador. Consultas explícitas ao NEB e sites externos precisam de internet.
Nenhuma consulta real ao NEB foi usada na verificação desta edição desktop.

A distribuição desktop é independente da lista de e-mails autorizados no site:
quem receber o instalador poderá executar o programa localmente. A versão web
mantém seu endereço e suas permissões atuais.

VALIDAÇÃO DA VERSÃO 1.14.0

283 testes do núcleo científico e 10 testes específicos do desktop passaram
localmente. No Linux, foram testados geração de exemplos Gibson e TPA,
salvamento/reabertura de projeto e exportação SnapGene. O arquivo SnapGene
exportado foi conferido: 3.000 pb e 18 registros de primers.

Os instaladores 1.14.0 de Windows e macOS foram compilados em executores
desses sistemas. A verificação visual daquela versão foi feita em Linux.

CORREÇÃO MACOS 1.14.1

O núcleo científico permanece na versão 1.14.0. Os novos pacotes macOS
passaram por verificação de integridade do DMG e assinatura do aplicativo,
além de teste nativo de inicialização e leitura/gravação de projeto.
Em Apple Silicon, o exemplo sintético gerou 2.334 pb e seis primers.
A aprovação inicial pelo Gatekeeper em uma máquina de usuário com
instalação limpa ainda não foi verificada. Detalhes:
https://github.com/bonattod/assembly-studio-desktop/blob/main/VALIDATION.md

As verificações computacionais não equivalem à validação experimental.
O arquivo SHA256SUMS fornecido permite conferir a integridade dos downloads.
